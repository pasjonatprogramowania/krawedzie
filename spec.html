TL;DR

RoundEdge to webowa aplikacja, która pozwala osobom bez wiedzy technicznej o CAD/meshopracowaniu wgrać model 3D (STL/OBJ/3MF), zaznaczyć krawędzie do zaokrąglenia i otrzymać zoptymalizowany plik gotowy do druku 3D — z automatycznym doborem parametrów pod kątem m.in. wytrzymałości, redukcji naprężeń i jakości powierzchni.

Analogia: tak jak Canva uprościła grafikę, tak RoundEdge upraszcza przygotowanie modelu do druku 3D.

🎯 Obietnica: „Wgraj model → zaznacz krawędzie → pobierz zoptymalizowany STL w 2 minuty."

01Dlaczego zaokrąglanie krawędzi ma znaczenie

Ostre krawędzie w modelach 3D to jeden z głównych powodów problemów w druku 3D. Na podstawie źródeł (Pollen AM, BigRep, Markforged, DfAM guides):

PowódMechanizm
Redukcja naprężeńOstre narożniki wewnętrzne to koncentratory naprężeń — zaokrąglenie (nawet 2 mm) znacząco zwiększa wytrzymałość
Jakość powierzchniOstre krawędzie zewnętrzne powodują drgania głowicy i artefakty
Mniej wsparćZaokrąglone krawędzie poprawiają overhangi, mniej potrzeba supportów
Mocniejsze delikatne elementyCienkie wypusty (np. uchwyty) łączone zaokrągleniem są 2-3× mocniejsze
EstetykaDetale wyglądają profesjonalnie, łatwiej zdjąć supporty
BezpieczeństwoBrak ostrych kantów = bezpieczniejsze użytkowanie (zabawki, uchwyty)

02Proces użycia — User Flow

Profesjonaliści vs. RoundEdge

Profesjonalny flow (Blender): Import STL → sprawdź manifold → konwersja do siatki → edge select mode → bevel tool → adjust narożników → sprawdź non-manifold → re-eksport. Czas: 30-90 minut, wymaga wiedzy.
RoundEdge flow: Wgraj plik → zaznacz krawędzie (klik) → wybierz preset → „Zaokrąglij" → pobierz STL. Czas: 2-3 minuty, zero wiedzy technicznej.

Szczegółowy flow — ekran po ekranie

  • Walidacja: czy to poprawny mesh?

  • Tryby selekcji:
  • Klik — pojedyncza krawędź

  • Podświetlenie zaznaczonych (kolor/highlight)
  • Licznik: „Zaznaczono: 47 krawędzi"
  • Sugestie: „Wykryto 23 ostre krawędzie >60° — zaznaczyć?"

Algorytm — pipeline przetwarzania

# Pseudokod pipeline'u przetwarzania (worker)

from meshlib import mrmeshpy as mm

def round_edges(input_path, selected_edges, radius_mm, fillet_type):
    # 1. Load mesh
    mesh = mm.loadMesh(input_path)

    # 2. Validate & repair
    if not is_manifold(mesh):
        mesh = repair_topology(mesh)

    # 3. Detect selected edges (by user click indices)
    edges = find_edges_by_indices(mesh, selected_edges)

    # 4. Apply fillet / bevel
    if fillet_type == "fillet":
        settings = mm.MeshFillerSettings()
        settings.maxEdgeLen = radius_mm * 0.5  # adaptive
        result = mm.fillEdges(mesh, edges, settings)
    elif fillet_type == "chamfer":
        result = mm.bevelEdges(mesh, edges, radius_mm)

    # 5. Cleanup
    result = mm.selfIntersections(result).fix()

    # 6. Validate output
    assert is_manifold(result)
    assert not has_non_manifold_edges(result)

    # 7. Export
    mm.saveMesh(result, output_path)
    return output_path
Dlaczego MeshLib? Open-source, aktywnie rozwijany, ma bezpośrednie API do fillet/bevel edges, najszybszy w swojej klasie (C++ core + Python bindings).

05UX/UI — kluczowe decyzje

Zasady projektowe

  1. „Zero wiedzy technicznej" — terminologia ukryta za przyjaznymi nazwami (zamiast „bevel width" → „Jak bardzo zaokrąglić")
  2. Live preview wszędzie — każda zmiana parametru musi pokazać efekt w <500 ms
  3. Auto-detect > manual — domyślnie zaznacz wszystkie problematyczne krawędzie
  4. Bezpieczne domyślne — preset „Wytrzymałe" działa w 90% przypadków
  5. Mobile-responsive — viewer uproszczony, ale core działa
